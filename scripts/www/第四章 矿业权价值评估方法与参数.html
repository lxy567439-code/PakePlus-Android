第一节 收益途径评估方法

核心原理：收益途径基于预期收益原则和效用原则，将矿业权未来各期预期净收益折现到评估基准日，加总得到矿业权价值。三大核心参数：预期收益预期收益年限折现率

1.1 折现现金流量法 (DCF)

核心思想：预测矿业权未来各年的净现金流，用折现率折算到评估基准日加总。

P = Σt=1n [ (CIt - COt) / (1 + i)t ]

其中：CI = 营业收入，CO = 营业总成本（含税费），i = 折现率，n = 收益年限

要素说明
适用对象采矿权（生产矿山为主），也可用于探矿权（需预测后续勘查投资）
前提条件有充分的历史经营数据或可靠的可行性研究/矿山设计文件
关键参数销售收入、经营成本、税费、折现率、收益年限
优点逻辑严谨、参数可追溯、适合大型矿山
局限参数多、预测主观性大、对数据质量要求高

1.2 收入权益法

核心思想：以销售收入为基础，乘以权益系数（反映矿业权人在收益中的份额），再折现。

P = Σt=1n [ St × K / (1 + i)t ]

其中：St = 第t年销售收入，K = 权益系数（0<K<1），i = 折现率

⚠️ 易混点：收入权益法 ≠ 折现现金流量法。收入权益法不逐项预测成本，而是用"权益系数"打包处理所有成本；DCF则逐项预测收支。权益系数通常由经验或行业数据确定。
对比项DCF收入权益法
收益基础净现金流（收入-成本）销售收入 × 权益系数
参数数量多（逐项预测）少（只需收入+权益系数）
适用场景数据完整的大型矿山数据有限、快速评估

1.3 折现现金流量风险系数调整法

核心思想：先用DCF算出基准价值 P₀，再乘以风险调整系数 (1-R)，得到考虑风险后的矿业权价值。

P = P₀ × (1 - R)

其中：P₀ = 折现现金流量法计算值，R = 风险系数（0≤R<1）

🔑 关键规则：使用此方法计算可采储量时，各种资源量应在项目经济合理性分析后全部参与评估计算，不使用可信度系数进行折算（这是与DCF的重要区别！）
⚠️ 适用范围：主要用于探矿权价值评估，或采矿权中地质条件复杂、不确定性大的情形。风险系数R的确定需综合地质风险、技术风险、市场风险等。

1.4 折现剩余现金流量法 (DRCF)

核心思想：在DCF基础上，进一步分离出"剩余现金流量"（即扣除全部显性成本后的超额收益），再折现。适用于需要更精细区分各类成本/收益层次的评估场景。

P = Σ [ (销售收入 - 经营成本 - 税金 - 所得税) / (1+i)t ]

与DCF区别：DRCF更强调"剩余"概念，通常用于矿业权出让收益评估等特定场景，计算口径与准则要求一致。

1.5 剩余利润法

核心思想：矿业权价值 = 矿山正常经营利润 - 企业正常投资应得的合理回报，剩余部分即为矿业权（资源）贡献的利润，折现后即为矿业权价值。

P = Σ [ (年利润 - 正常投资×投资收益率) / (1+i)t ]
⚠️ 使用限制：剩余利润法对"正常投资"和"投资收益率"的确定非常敏感，实务中应用较少，多见于理论分析。

第二节 收益途径评估参数

收益途径评估需要确定四大类参数：税费参数矿产品销售价格技术经济参数折现率

2.1 税费参数

税费种类关键要点
增值税一般计税13%（部分矿产品9%），可抵扣进项税；评估中通常用不含税价格
城市维护建设税以实缴增值税为基数，税率7%（市区）/5%（县城）/1%（其他）
教育费附加以实缴增值税为基数，税率3%
地方教育附加以实缴增值税为基数，税率2%
企业所得税法定税率25%（小型微利企业等优惠另计）
资源税从价计征为主，税率因矿种和地区而异（1%-20%不等）
行政事业性收费/政府性基金如矿山地质环境恢复治理基金、土地复垦费等，按当地规定
🔑 高频考点：① 企业所得税率 25%；② 城建税+教育费附加+地方教育附加 = 实缴增值税 × (7%+3%+2%) = 12%（市区）；③ 评估中矿产品价格通常采用不含增值税价格。

2.2 矿产品销售价格

信息来源

  • 评估对象所在地的市场价格（优先）
  • 国家/行业主管部门发布的指导价
  • 矿产品交易市场公开报价
  • 企业历史销售价格（需剔除异常）
  • 同类矿山销售价格对比

确定原则

  • 价格时点一致性：销售价格应与评估基准日价格水平一致
  • 不含税原则：一般采用不含增值税的销售价格
  • 合理性检验：价格应处于合理区间，排除异常偏高/偏低
  • 产品方案匹配：价格应与确定的产品方案（品级、规格）对应

考虑因素

  • 矿产品供需关系、行业周期
  • 运输距离与物流成本（坑口价 vs 到厂价）
  • 品位/质量差异（高品位溢价、低品位折价）
  • 市场半径与销售半径
  • 长期趋势（是否考虑价格衰减）
⚠️ 易错提醒：表4-1规定了历史实际价格取值时段——评估基准日前3年内的平均价格或评估基准日当期价格，取合理者。不能随意取历史最高价或最低价。

2.3 技术经济参数

技术经济参数是收益途径评估中数量最多、最复杂的一类：

参数确定依据注意事项
生产能力采矿许可证核定规模、矿山设计、实际产量三者不一致时按"就低不就高"或评估目的确定
服务年限可采储量 ÷ 年生产能力注意是否含建设期、达产期
资源储量储量报告（见第五节）需经可信度系数折算
固定资产投资矿山设计文件、可行性报告注意价格水平调整、口径一致性
土地/用地用地性质、取得方式出让/租赁/自有，影响成本结构
经营成本矿山设计、生产报表、行业定额区分可变成本与固定成本
销售收入价格 × 产量 × (1-损耗率)与价格参数联动
技术指标采矿回采率、采矿损失率、矿石贫化率、选矿回收率来源：设计文件 > 生产实际 > 行业定额
权益系数行业经验、类似案例收入权益法专用
风险系数地质/技术/市场风险综合判断风险系数调整法专用
投资收益率行业平均、资本成本剩余利润法专用

2.4 折现率

折现率 = 无风险报酬率 + 风险报酬率

无风险报酬率：通常取评估基准日前5年期国债到期收益率（或相近期限）。

风险报酬率：采用风险累加法，将各类风险逐一量化后加总：

风险因素参考取值范围说明
地质风险0.5% ~ 2.0%勘查程度、矿体稳定性
技术风险0.5% ~ 2.0%开采难度、选冶技术成熟度
市场风险0.5% ~ 2.0%价格波动、供需变化
管理风险0.5% ~ 1.5%企业管理水平、安全生产
政策风险0.5% ~ 2.0%环保政策、矿业权政策变化
🔑 高频考点：① 折现率 = 无风险 + 风险（累加）；② 无风险取5年期国债收益率；③ 风险累加法各分项之和通常为 2%~6% 区间，总折现率一般 5%~12%；④ 不同矿种、不同勘查程度，风险报酬率不同。
⚠️ 易错提醒：折现率不能简单取"行业平均"，必须根据具体评估对象的实际风险逐一累加。同一矿山不同时期（勘查期 vs 生产期）风险不同，折现率可能不同。

第三节 成本途径评估方法

核心原理：成本途径从"重置"角度出发，以取得同等条件的矿业权所需支出的合理成本为基础确定价值。多用于探矿权评估

3.1 勘查成本效用法

P = C × F = [Σ(Ui × Pi × (1+ε))] × F

其中：

  • C = 勘查成本（有效勘查投资）
  • Ui = 第i种勘查工作量（如钻孔米数、坑道米数、测量面积等）
  • Pi = 第i种工作量的现行单价
  • ε = 调整系数（地质风险/勘查程度调整）
  • F = 成本效果系数（反映勘查成果的经济效果）
要素说明
适用对象探矿权（勘查阶段，尚无可靠收益预测）
核心逻辑已投入的有效勘查投资 × 效果系数 = 探矿权价值
关键参数勘查工作量、现行单价、调整系数ε、成本效果系数F
优点参数客观（基于实际投入），适合早期勘查项目
局限不能反映资源潜力/前景价值；F的确定较主观
🔑 核心考点：① 只计"有效"勘查投资（无效的、与勘查无关的支出不计入）；② 单价用现行价格（不是历史价格）；③ F（成本效果系数）是核心调整项，反映勘查发现资源的可能性。

3.2 地质要素评序法

P = Pc × α

其中：Pc = 可比探矿权价值（基准价），α = 地质要素调整系数（综合评序结果）

要素说明
适用对象探矿权（有可比案例）
核心逻辑找可比探矿权交易案例 → 按地质要素逐项评分 → 调整得到目标探矿权价值
关键参数可比案例价格Pc、地质要素权重与评分、调整系数α
地质要素矿种、矿床类型、地质条件、勘查程度、资源潜力、区域成矿前景等
⚠️ 使用注意：可比案例的选择要求较高（同区域、同矿种、相近勘查程度），实务中可比案例往往不足，使用受限。

📝 考点自测 · 第三节

Q1：成本途径主要适用于哪种矿业权（探矿权/采矿权）？
Q2：勘查成本效用法公式中，F代表什么？ε代表什么？
Q3：地质要素评序法中，Pc是什么？α如何确定？
A1：探矿权（勘查阶段，无可靠收益预测时）
A2：F = 成本效果系数（反映勘查成果经济效果）；ε = 调整系数（地质风险/勘查程度调整）

第四节 市场途径评估方法

核心原理：市场途径基于替代原则，通过参照市场上类似矿业权的交易价格，经适当调整后确定评估对象价值。需要可比交易案例

4.1 可比销售法

核心思想：选取近期同类矿业权交易案例，对影响价值的关键因素逐项调整，得到评估对象价值。

调整系数（逐项）

调整因素说明
可采储量调整按评估对象与可比案例的可采储量差异调整
品位/质量调整按平均品位、有用组分含量差异调整
生产规模调整按核定生产能力差异调整
价格调整按交易时点矿产品价格差异调整
赋存条件调整按开采难度、水文地质等条件差异调整
区位/交通调整按地理位置、运输条件差异调整
其他权属完整性、剩余服务年限等
P = P可比 × 储量系数 × 品位系数 × 规模系数 × 价格系数 × 赋存系数 × 区位系数 × …
🔑 核心考点：① 可比案例要求"近期、同类、同区域优先"；② 调整因素越多，主观性越大，需逐项说明理由；③ 一般要求至少2~3个可比案例交叉验证。

4.2 单位面积探矿权价值评判法

核心思想：以每单位面积（km²）探矿权交易价格为基准，结合勘查程度、资源前景等因素，评判评估对象探矿权价值。

P = 单位面积价值（元/km²）× 勘查区面积 × 调整系数
要素说明
适用对象探矿权（区域成矿背景好、可比单位面积价格可得）
关键参数单位面积基准价、勘查区面积、调整系数
局限忽略矿体具体特征，精度较低，适合初步/粗略评估

4.3 资源品级探矿权价值估算法

核心思想：将探矿权按资源前景/勘查程度分为若干"品级"，每个品级对应一个价值区间，评估对象归入相应品级后确定价值。

要素说明
适用对象探矿权（有明确品级标准体系时）
品级划分依据区域成矿条件、已有发现、勘查程度、资源潜力
关键参数品级标准、各品级价值区间、评估对象归级
局限品级划分和对应价值区间需行业共识或主管部门发布
⚠️ 市场途径共同局限：矿业权交易案例相对稀缺（尤其国内），可比性判断主观性强。实务中市场途径多作为辅助验证，而非主要方法。

第五节 矿业权价值评估中矿产资源储量处理

矿产资源储量既是评估对象的范围要素，也是重要的评估参数。本节核心：如何从"保有资源储量"一步步折算到"评估利用可采储量"。

5.1 储量分类体系

类别分类标准要点
固体矿产GB/T 17766—2020查明（探明/控制/推断资源量 + 证实/可信储量）+ 潜在资源；能利用 + 尚难利用
油气矿产GB/T 19492—2020地质储量（探明/控制/预测）→ 技术可采储量 → 经济可采储量
地热/矿泉水GB/T 15218—2021储存量、补给量、可采量；允许开采量分A/B/C/D/E五级精度

5.2 储量折算链（核心公式）

保有资源储量 → ×可信度系数 → 评估利用资源储量 → −设计损失 → ×回采率 → 评估利用可采储量

第一步：参与评估的保有资源储量

参与评估的保有储量 = 储量核实基准日保有储量 − 期间动用储量 + 期间净增储量

（评估基准日在储量核实基准日之后时）

第二步：动用资源储量

动用储量 = 采出矿石量 × (1 − 矿石贫化率) ÷ 采矿回采率 + 采矿损失量

第三步：评估利用资源储量

评估利用资源储量 = 参与评估的储量 + 资源量 × 可信度系数
  • 储量（证实/可信）→ 直接使用，可信度系数 = 1.0
  • 探明/控制资源量 → 可信度系数 = 1.0（技术经济可行时）
  • 推断资源量 → 可信度系数 0.5~0.8（参考设计规范）
  • 风险系数调整法下：不乘可信度系数，各种资源量全部参与

第四步：评估利用可采储量

可采储量 = (评估利用资源储量 − 设计损失量) × 采矿回采率

其中：采矿损失量 = (评估利用资源储量 − 设计损失量) × 采矿损失率

5.3 关键定义速查

术语定义
矿产资源储量报告勘查报告、储量核实报告、检测报告、资源评价报告、生产勘探报告等
参与评估的保有资源储量评估对象范围内、评估计算时点（通常=评估基准日）的保有储量
可信度系数将资源量折算为评估利用资源储量的系数（考虑不确定性）
评估利用资源储量以参与评估的保有储量为基础，按判断原则估算的储量
评估利用可采储量评估利用资源储量 − 设计损失 − 采矿损失 = 可采出的储量

5.4 确定原则

  • 储量可直接作为评估利用资源储量（系数=1.0）
  • 探明/控制资源量：技术经济可行时，系数=1.0
  • 推断资源量：参考设计规范，系数0.5~0.8；设计未利用或规范未规定的，0.5~0.8
  • 尚难利用/低品位矿：原则上不参与；设计利用或经济分析认为可利用的，可参与
  • 潜在矿产资源：原则上不参与计算
  • 出让收益评估：自然资源行政主管部门有规定的从其规定
🔑 高频考点：① 金属矿产需同时按矿石量和金属量折算，同类型折算前后品位不变；② 设计损失和开采损失是"技术方案安排"，不是对储量的调整，也不是国有资源损失；③ 可后期回收的矿柱不归为永久矿柱（不算设计损失）；④ 永久矿柱 ≠ 压覆矿产资源，不能混同。

第六节 矿业权价值评估中专业报告的利用

评估中常需利用三类专业报告：后续地质勘查设计文件矿山设计文件企业财务会计报告

6.1 后续地质勘查设计文件的利用

定义：评估基准日后尚需进一步进行详查/勘探或补充勘查工作而编制的地质勘查设计文件。

利用要点（9条）

  1. 须符合《固体矿产地质勘查规范总则》及分矿种规范要求
  2. 分析勘查技术方法手段和工作量布置的合理性
  3. 以各种地质勘查工作满足矿山开采设计基本要求的程度为宜
  4. 直接勘查费用：按现行价格核实利用（合同编制的可直接利用）
  5. 间接勘查费用：参照单项现行价格，或按占直接费用比例确定
  6. 不计入：进一步验证异常、寻找新矿体、以增加储量为目的的勘查工作量
  7. 后续勘查期应合理（参考劳动定额和一般施工进度），明显不合理时重新确定
  8. 评估报告中应清晰陈述利用的勘查工作量、现行价格和勘查期
  9. 应对利用文件的可靠性、适用性作出适当说明

6.2 矿山设计文件的利用

文件类型及精度要求

文件类型投资/成本估算误差说明
初步可行性研究报告≤ 20%机会研究与可行性研究之间的中间阶段
可行性研究报告≤ 10%投资决策基础，编制项目设计的基础
初步设计—施工图设计和施工组织设计的基础
矿产资源开发利用方案—按"安全、高效、科学、经济、充分利用资源"原则编制

利用注意事项（核心12条）

  1. 编制单位资质要求从其规定；有审查意见的同时利用
  2. 正常生产矿山以生产实际为依据，设计文件仅作参考
  3. 关注设计文件中披露的影响评估结论的问题与建议
  4. 通常利用距评估基准日最近的设计文件；重大变化时要求重新提供
  5. 资源储量：核对设计依据储量与评估对象范围是否一致；不一致时不能直接利用
  6. 开发方案：核查开采方案与赋存条件匹配性、选冶工艺与矿石质量匹配性、产品方案与工艺匹配性
  7. 技术指标：了解确定依据，分析与开采方式/矿石质量/工艺的匹配性；设计指标 vs 生产实际指标有差异
  8. 生产能力：核查设计能力、许可证规模、核定能力、实际能力的一致性；不一致时合理确定
  9. 建设期/达产期/生产负荷：一般可直接利用，不一致时说明理由
  10. 固定资产投资：能力不一致时不直接利用；价格水平差异大时调整；口径差异需调整；改扩建造山需分析是否含原有资产
  11. 成本费用：口径不一致时不直接利用；关注材料燃料动力费是否含进项增值税（通常按不含税）；价格水平差异大时调整；税费种类标准变化时按现行政策调整
  12. 报告披露：披露利用的设计文件主要内容，说明可靠性和适用性
🔑 高频考点：① 可研投资误差≤10%，初可研≤20%；② 正常生产矿山以生产实际为主，设计文件仅参考；③ 设计文件编制日期早于储量报告编制日期且对开发方案有重大影响时，不能直接利用；④ 可后期回采的临时矿柱未设计利用的，考虑是否利用并说明理由。

6.3 企业财务会计报告的利用

文件构成

会计报表（资产负债表、利润表、现金流量表、所有者权益变动表）+ 附注 + 其他披露资料

利用条件与范围（9条核心）

  1. 建议用经注册会计师审计的报告
  2. 利用与评估基准日一致的年末（或阶段）报表；不同时需了解日后调整/非调整事项
  3. 关注合并报表、分部报告与矿山企业的对应性
  4. 系统分析附注中的重要会计估计、资产负债表日后事项
  5. 固定资产等账面价值 = 原始发生额 − 折旧/摊销 − 减值准备
  6. 关注非正常因素（季节、周期、非正常停工、超规模开采、关联交易、偶然性收支），分析调整后确定参数
  7. 能确认未来信息时，不再利用以往报告对应信息；关注税费种类与基准日政策一致性
  8. 确定固定资产/无形资产投资额时，分析是否含增值税，按准则确定
  9. 关联交易/不公平交易可能影响成本、价格、收入等，需收集关联信息并分析影响
⚠️ 易错提醒：① 会计报表中的固定资产、在建工程、工程物资、无形资产等账面价值是扣除折旧/摊销/减值后的，不能直接用作评估用投资额；② 材料燃料动力费设计指标通常含进项增值税，评估时一般按不含税口径；③ 能确认未来信息（如已签合同价格）时，优先用未来信息而非历史报表。
