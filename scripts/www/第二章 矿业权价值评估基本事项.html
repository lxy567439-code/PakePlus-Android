第二章 矿业权价值评估基本事项

本章是"打地基"的一章——讲清楚一次评估"谁委托、为什么评、评什么、何时算、在什么前提下算"。这五大基本事项（当事人与委托、目的、对象与范围、基准日/报告日/有效期、假设）是形成一切评估结论的逻辑前提，也是命题最密集的考点区。

1矿业权价值评估业务承接

承接业务前先搞清两件事：谁是委托人、谁是相关当事人，以及哪些是法定评估业务、谁委托、怎么委托。这是本章最易考"对应关系"的环节。

一、委托人与相关当事人

（一）委托人

定义：与矿业权评估机构就专业服务事项签订委托合同的民事主体。可以是一个或多个，可以是法人或自然人。

👉 委托人权利（4条·《资产评估法》）

  1. 自主选择权：自主选符合规定的评估机构，任何组织/个人不得非法限制干预。
  2. 回避请求权：要求与相关当事人及评估对象有利害关系的评估专业人员回避。
  3. 解释请求权：对评估报告有异议，可要求评估机构解释。
  4. 投诉举报权：认为机构/人员违法开展业务的，可向行政管理部门或行业协会投诉、举报。

👉 委托人义务（4条·《资产评估法》）

  1. 付费义务：按合同约定付费，不得索要、收受或变相回扣。
  2. 资料责任：对提供的权属证明、财务会计信息和其他资料的真实性、完整性、合法性负责。
  3. 不串通：不得串通、唆使机构或人员出具虚假评估报告。
  4. 合理使用：按法律规定和报告载明的使用范围使用评估报告。
📌 委托人还应为执行评估业务的专业人员提供必要的工作条件和帮助。

（二）相关当事人

① 矿业权人 / 矿业权申请人
矿业权人 依法取得矿业权的自然人、法人或其他经济组织，享有占有、使用、收益、处分权并承担义务。
申请人 申请取得矿业权的主体。
委托人可能是矿业权人/申请人，也可能不是。若委托人不是，需根据业务需要，为评估专业人员与矿业权人/申请人之间的协调提供必要协助。

② 评估报告使用人
指法律、行政法规规定的，或委托合同中约定的有权使用评估报告或评估结论的当事人。
除委托人、合同约定使用人、法律规定使用人外，其他任何机构和个人不能称为使用人。使用人未按规定的范围方式使用报告的，机构和专业人员不承担责任；对非使用人使用的后果也不承担。

二、法定评估业务及其委托（5 类）

法定评估业务：涉及国有资产或公共利益等事项，法律、行政法规规定需要评估的业务（《资产评估法》）。下面 5 类是核心考点，记牢"行为 + 委托人 + 委托方式"三要素：

类别涉及的经济/管理行为委托人（通常）委托方式
① 矿业权管理 出让、转让、变更、延续、扩界等涉及缴纳出让收益；招拍挂需确定底价/保留价；地勘基金及财政预算项目评估。 自然资源行政主管部门 或 地质勘查基金中心 公开摇号 或 招投标
② 涉矿国资管理 国企改建、矿业权对外投资、合并分立破产解散、股权转让、产权转让、矿业权转让置换、租赁给非国有单位、偿债、涉讼、收购/接受非国有单位出资或抵债、处置不良资产等 14 项。 国有企业 招投标，在其评估机构备选库中选择
③ 非现金资产出资 以探矿权、采矿权作价出资（《公司法》）。 涉及国资→按国资规定；不涉及国资→出资人(股东)/公司/共同委托 《公司法》未明确规定，按上述规则
④ 涉及上市公司 设立、IPO、投资、再融资(配股/增发)、可转换债券、重大资产重组(含借壳)、非公开发行债券等涉及矿业权。 上市公司 委托经证监会备案的矿业权评估机构
⑤ 涉及司法领域 案件涉及矿业权价值的司法鉴定；确定财产处置参考价需委托评估；其他司法机关办案需评估。 各级人民法院（极少数为相关当事人） 随机摇号在司法评估机构名单库中选择
⚡ 易混点对比：①管理→"公开摇号/招投标"；⑤司法→"随机摇号"；②国资→"备选库中招投标"。三处委托方式不同，是判断题/选择题高频陷阱。
📌 补充：建设项目压覆重要矿产资源确定矿业权价值时，通常涉及国有资产，一般由项目建设方、施工方或被压覆方单独或共同委托。
✏️ 第一节 考点自测
  1. 委托人认为评估机构违法开展业务，可采取什么救济？
    ✔ 可向有关评估行政管理部门或行业协会投诉、举报。
  2. 涉及上市公司重大资产重组（含借壳）的矿业权评估，委托人通常是谁？委托方式？
    ✔ 委托人通常是上市公司；依法委托经证监会备案的矿业权评估机构。
  3. 涉矿国有资产管理的法定评估，国有企业采取什么方式、在哪里选择机构？
    ✔ 招投标方式，在其评估机构备选库中选择。
  4. 除委托人外，谁也不能称为"评估报告使用人"？
    ✔ 合同约定使用人或法律/行政法规规定使用人之外，其他任何机构和个人。

2矿业权价值评估目的

评估目的是评估任务的"根"，是方向性指引——它直接决定评估程序、途径、方法、参数，以及委托人如何使用结论。

一、概念与作用

概念（《矿业权评估技术基本准则》）：为满足特定经济行为的需要，或为交易提供价值参考依据。评估总是为满足特定管理/经济行为或会计计量的需要进行，需要来源于矿业权管理和矿业权市场。

作用① 直接影响评估行为

专业人员根据目的确定程序、途径、方法、参数，使结果与目的逻辑一致。理论上，同一矿业权、同一基准日，出于不同目的，结果不必然一致。

作用② 直接影响结论使用

评估直接为委托人实现某种管理/经济行为而发生，不同目的对应不同使用目的。

二、四种常见评估目的

目的含义与要点典型提示
① 矿业权出让 国家将矿产资源使用权让渡给矿业权人，赋予勘查、开采权利和部分收益权。出让时应征收体现所有者权益的出让收益。 竞争方式出让→评估为确定出让底价提供参考；协议出让→为确定出让收益提供参考。
② 矿业权转让 矿业权人将矿业权转移的行为：出售、作价出资、合作、重组改制、出租、抵押、非货币性资产交换、债务重组等。 进入市场后最常见行为；有法定评估也有自愿委托的非法定评估。不同方式应分别独立表述为相应经济行为，据此确定目的。
③ 资产会计计量 服务于会计计量和财务报告编制。公允价值计量引入会计系统催生此类评估。 资产减值测试（《企业会计准则第8号》：可收回金额 vs 账面价值，确认减值损失）；合并对价分摊。
④ 矿业权价值鉴定 主要出现在司法、纪检监察等领域办案中的矿业权价值鉴定、非法开采矿产资源价值损失鉴定等。 不同案件实质涉及不同经济行为，要按案件实际确定目的。

三、评估目的的披露

📌 目的应唯一、明确、清晰。业务约定书载明的目的应唯一；报告中应载明目的并注明"为满足报告使用者的何种需要"。
  • 经济行为决定评估目的：先清晰说明具体经济行为，再按准则格式写明具体目的。
  • 报告中描述的经济行为应与评估依据列示、附件经济行为文件内容一致；描述的目的应与业务约定书约定一致。
  • 涉及矿业权出让（出让收益评估）：委托人是自然资源主管部门或矿业权申请人；申请人委托时，目的应表述为"自然资源主管部门确定出让收益(或底价)提供参考意见"，而非"为委托人提供价值参考"。
  • 涉及转让等：应明确描述所要服务的具体经济行为背景，不能简单写成"为了解矿业权价值提供参考意见"。
✏️ 第二节 考点自测
  1. 同一采矿权、同一基准日，因目的不同，评估结果是否必然一致？
    ✔ 不必然一致——目的不同对应不同的程序/方法/参数/用途。
  2. 以协议方式出让矿业权时，评估为确定什么提供参考意见？
    ✔ 矿业权出让收益。（竞争方式出让→出让底价）
  3. 矿业权申请人委托出让收益评估，目的应如何规范表述？
    ✔ 表述为"自然资源主管部门确定矿业权出让收益(或出让底价)提供参考意见"。
  4. 资产会计计量中最常见的矿业权评估业务是什么？
    ✔ 资产减值测试（另有合并对价分摊）。

3矿业权价值评估对象与范围

对象 = 评估客体（标的），回答"对什么"估价值；范围 = 对对象组成、结构的补充。矿业权的范围是空间概念（与法律主体/会计主体完全不同）。对象与范围由一组要素界定，一个对象对应唯一要素组合。

一、对象名称

对象就是矿业权：探矿权、采矿权，以及与之相关的经济权益（所有者权益、股权、金融权益等）。

探矿权评估对象

固体矿产普查/详查/勘探探矿权、油气探矿权、地热与矿泉水探矿权等。

采矿权评估对象

在建、拟建矿山 + 生产矿山采矿权；还包括闭坑矿山、矿业权出让收益(所有者权益)、股权、金融权益等。

二、要素构成（核心考点·T/C 编号）

⚠ 口诀：探矿权 T1–T7（7 要素），采矿权 C1–C9（9 要素）。要素不同→价值不同；同名矿业权要素组合不同→价值不同。

🔎 探矿权评估范围 = T1…T7

编号要素
T1地质勘查阶段
T2勘查矿种（有前提条件的勘查矿产(种)）
T3确定的勘查(区)范围
T4勘查区范围拐点坐标
T5确定的勘查(区)面积
T6矿产资源储量估算范围、资源储量类型及其数量
T7其他影响矿业权价值的登记状态、权利状态、物理状态因素

⛏ 采矿权评估范围 = C1…C9

编号要素
C1建设或生产阶段
C2开采矿种（有前提条件的共(伴)生有用组分）
C3确定的开采方式
C4某一生产规模
C5确定的矿区面积
C6矿区范围拐点坐标
C7确定的开采深度
C8矿产资源储量估算范围、资源储量类型及其数量
C9其他影响矿业权价值的登记状态、权利状态、物理状态因素

对对象与范围的理解（5 个要点）

  1. 对象与范围是评估客体，回答"对什么"估价值；由一组要素构成不可分割的整体，一对象对应唯一要素组合。
  2. 地质勘查阶段要素与资源储量要素不可分割；资源储量基于一定估算标准，既是要素又是评估参数（作为参数考虑）。
  3. 资源储量因可靠性/经济性差异、勘查阶段不同、估算标准不同，不能简单直接数量比较。
  4. 矿山建设设计折扣(量)与开采损失折扣(量)均属于设计技术范畴，不是对对象与范围的调整；以可采储量得出的评估结果针对的是评估范围，而非可采储量。
  5. 有用组分、共(伴)生矿、勘查矿种等作为评估值估算基础，属于评估对象与范围。

三、对象与范围的确定

由委托人根据其拟实施的经济行为确定，并在评估委托合同中约定；报告中描述的对象与范围应与委托合同约定一致。

四、对象与范围的披露

  • 权利客体为已查明或潜在的矿产资源储量；权利主体为矿业权人；权利价值内涵为用益物权价值（一般情况是已查明或潜在储量开发价值的一部分）。
  • 应依据有效的勘查/采矿许可证、划定矿区范围批复文件等分别介绍对象和范围。
  • 已取得勘查许可证：描述证号、探矿权人、勘查项目名称、勘查面积、拐点坐标、地理位置、有效期限、勘查单位。
  • 已取得采矿许可证：描述证号、采矿权人、矿山名称、开采矿种、开采方式、生产规模、矿区面积、拐点坐标、开采深度、有效期限。
  • 可用文字、示意图全面反映评估范围与资源储量估算范围、矿业权权属范围等的相互关系。
✏️ 第三节 考点自测
  1. 探矿权与采矿权评估范围各包含几个要素？
    ✔ 探矿权 T1–T7 共7个；采矿权 C1–C9 共9个。
  2. 资源储量"既是评估对象与范围要素，又是评估参数"，为什么？
    ✔ 它是基于一定估算标准的结果，作为矿业权有偿处置的重要依据，具有管理特点，故作为参数考虑。
  3. 对象与范围由谁确定、在哪里约定？
    ✔ 由委托人根据拟实施的经济行为确定，并在评估委托合同中约定。
  4. 以可采储量得出的评估结果，针对的是评估范围还是可采储量？
    ✔ 针对评估范围而言，而非可采储量。

4评估基准日、评估报告日与评估结论使用有效期

三个日期：基准日（何时算）、报告日（何时出）、有效期（算出来能用多久）。它们直接决定评估价值，也关系机构与专业人员的责任。

一、评估基准日

概念（《确定评估基准日指导意见》）：评估结论是一个时点价值，这个时点能有效服务于评估目的，它就是基准日。基准日是判断矿业权价值的基准时点、评估结论生效的特定时日，通常以日历中具体日期表示。

同一矿业权不同时点价值不同——除货币自身价值变化外，更重要的是矿业权内涵可能变化（如勘查持续→储量类型数量变化；市场/供需变化→交易价值变化）。

现时性 / 追溯性 / 预测性：一般应是现在时点（现时性）特殊业务可为过去时点（追溯性）或将来时点（预测性）

基准日的确定（4 因素）

  1. 评估目的及对应经济行为可能涉及的其他专业评估的基准日。
  2. 法律和行政法规、政府主管部门、相关单位的规定。
  3. 基准日尽可能接近经济行为实现日（或交易结算日），减少期后调整事项。
  4. 评估所需资料的可取得性、使用方便性及财务会计结算制度，同时利于合理选择评估参数。
📌 基准日由委托人确定，并在委托合同（业务约定书）中约定，专业人员可凭经验提供建议。若有效期内评估未完成或未出报告，应及时与委托人沟通，采取调整基准日等措施。

二、评估报告日与期后事项

报告日：专业人员形成评估结论最终专业意见、评估机构出具评估报告的日期。

期后事项（基准日→报告日之间发生、可能影响结论的事项），分 4 类：

矿权本身重大变化矿业权及对应矿产地/勘查地本身的重大变化事项。
重大自然灾害重大自然灾害的影响事项。
财税货币政策调整评估依据的国家相关财税货币政策的调整事项。
市场参数重大变化评估依据的市场参数的重大变化。

期后事项的两种处理

思路① "调整"思路

把已知的、对结论产生影响的事项直接在估算评估值时考虑，并在期后事项中披露。注意：基准日"一切取价依据均以基准日有效价格标准"不适用。涉及实施日期以基准日为界——实施日在基准日前→按文件/公告内容确定参数；实施日在基准日后→考虑前后不同处理。

思路② "披露"思路

对受专业手段限制、难以量化的期后事项进行披露。如自然灾害/经营事故导致的资产损失（说明时间、地点、损失估计数及影响）；外汇汇率较大变动（说明外币金额及影响数额及利弊）。

三、评估结论使用有效期

概念：评估结论运用于经济行为的时限，应根据国家相关政策规定、市场价格水平变化等确定。有效期针对基准日——对象与市场价格参数变动越大，有效期越短；变动越小，有效期越长。

⚡ 核心数字：基准日为现在时点时，评估结论使用有效期自基准日起原则上不超过 1 年；基准日为过去或将来时点时，结论仅针对基准日，一般无使用有效期限。
⚠ 重要区分：评估结论使用有效期 ≠ 评估报告的有效期 ≠ 评估责任期限。报告有效期是界定评估行为责任的期限。

现时点基准日的特殊情形（3 种）

  1. 非货币性资产交换、债务重组涉及的→可按相关规定或协议确定。
  2. 企业股权转让、资产组合转让涉及的→应与同时进行的其他专业评估结论使用有效期一致。
  3. 矿业权出让收益评估、司法领域涉及的→有规定的从其规定。

四、三事项的披露

  • 基准日：应准确、唯一；与委托合同(业务约定书)一致；如实说明选取考虑的因素；一个评估项目只能有一个基准日，不能出现两个及以上。
  • 期后事项：应做到应披露尽披露，准确、完整。
  • 有效期：是评估结论的重要组成，披露应恰当、准确、全面。
✏️ 第四节 考点自测
  1. 现时点基准日的评估结论使用有效期，原则上不超过多久？
    ✔ 自基准日起原则上不超过 1 年。
  2. "评估结论使用有效期"与"评估报告有效期/责任期限"是一回事吗？
    ✔ 不是。报告有效期是界定评估行为责任的期限，两者概念不同。
  3. 一个评估项目可以有两个基准日吗？
    ✔ 不可以，一个项目只能有一个基准日。
  4. 期后事项一般分哪 4 类？
    ✔ ①矿权本身重大变化 ②重大自然灾害 ③财税货币政策调整 ④市场参数重大变化。

5矿业权价值评估假设

评估假设是评估结论成立的前提条件。前提包括真实性条件和假设条件，由此产生"评估假设"概念。

一、基本概念与基本作用

概念：对矿业权权利登记状况、经济和市场环境、矿产资源勘查开发生产经营等方面的不确定信息，依据现有知识、政策、技术，通过有效合理的逻辑推理，作出的合理推断或假定，用于矿业权价值评估。

作用：揭示评估结论成立的约束条件，引导使用者正确理解和运用结论。假设变化→结论变化；假设重大变化→原结论可能不成立。

二、常见类型

（一）一般分类（5 种）

按实现可能性推测性假设（"如果…那么…"）/ 逆向假设（"如果不…则…"，反证合理性）。
按市场环境宏观政治、经济、社会环境稳定性，汇率、利率、税赋、通胀、产业政策、不可抗力等。
按交易方式公开市场假设、非公开市场假设；正常交易、强制出售及其他交易条件。
按企业存续状态持续经营、产权主体变动、破产清算、结业清算、改变经营方式/产品结构/主营业务等。
按矿业权状态继续占用或变现、探矿权缩减面积、探矿权转采矿权等。

（二）实务分类：A / B / C / D 四类（表 2-1）

分类针对对象假设性质主要假设内容
A 类 国家（或地区）的所有行业、所有企业 同一国家/地区→一般性；跨国/地区→针对性 政治、经济、文化体制及相关政策；货币政策(利率)、汇率；财政政策；产业政策。
B 类 同一行业（或地区）的所有企业 同一行业/地区→一般性；不同行业/跨国→针对性 行业准入；差别利率；区域经济政策（新区、开发区、振兴区）；环保、土地。
C 类 企业（针对企业） 针对性假设 生产经营模式；业务(产品)种类；业务规模、经营计划；行业地位；管理团队稳定、经营方式与水平；会计政策；税收优惠减免、汇率、政府补助；其他（如收益方式与分配协议）。
D 类 资产（针对资产） 针对性假设 继续占用或变现；探矿权增减面积；探矿权转采矿权；其他（如矿业权抵押/担保资产涉及债务到期得以偿还等）。
📌 注意：并非每个具体评估项目都包含 A/B/C/D 全部假设。

三、假设的使用

（一）使用四原则

① 合理性建立在一定依据、合理推断、逻辑推理之上，一般存在发生可能性（除逆向假设）。违背法规/政策/科学规律的假设不合理。
② 针对性针对具体预测参数。如以销售收入比例预测管理费，基准是"经营管理方式不变"；超出现有产能应追加资本投资。
③ 相关性与评估对象实际情况或结论形成过程相关。如溢余资产判断与收益单元口径判断有关。
④ 全面性涵盖与结论形成相关的各方面：控股权、主营方向、财税政策、经营销售策略、管理层与研发、后续投入及资本结构、协同效应等。

（二）使用考虑的基本因素（5 个）

  1. 评估目的：不同目的对应不同市场环境/交易方式/勘查开发阶段，结合目的设定。
  2. 经济行为：如抵押评估的最高最佳使用假设、股权转让的持续经营假设。
  3. 评估对象：探矿权/采矿权用不同假设。探矿权收益法必须建立在假设取得采矿权的条件上，否则开采不合法、销售不合规。
  4. 评估方法：市场途径→市场有效性/活跃性/可比性；收益途径→产品方案、生产规模持续经营。
  5. 评估资料：完整性是相对概念、必要性是绝对概念；应设定资料完整性假设，依据不同资料会得不同结论。

四、假设的披露

  • 假设披露应与评估结论对应，结论与假设具有唯一对应性，不同假设对应不同结论。
  • 完整、准确披露所利用的相关专业报告是结论成立的必要条件。
  • 应说明如果假设改变，将对结论产生重大影响。
✏️ 第五节 考点自测
  1. A、B、C、D 四类假设分别针对什么对象？
    ✔ A国家(或地区)所有行业/企业；B同一行业(或地区)所有企业；C企业；D资产。
  2. 推测性假设与逆向假设各用什么分析框架？
    ✔ 推测性"如果…那么…"；逆向"如果不…则…"（与已知事实相反，反证合理性）。
  3. 评估假设使用的四个基本原则是什么？
    ✔ 合理性、针对性、相关性、全面性。
  4. 探矿权收益法评估必须建立在什么假设条件之上？
    ✔ 假设取得采矿权的条件之上（否则矿产开采不合法、销售不合规）。
