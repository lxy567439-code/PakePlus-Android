报告定义

专业人员履行必要程序后，对评估对象在评估基准日特定目的下的价值发表的、由评估机构出具的书面专业意见

三大属性

①法定成果 ②最终档案资料 ③机构与人员执业能力的体现

四类划分

法律定位（法定/非法定）、评估对象（探/采/权益）、业务类型（出让/转让/国资/上市/法院）、基准日时点（现时/追溯/预测）

咨询报告

限制使用性质，仅供了解价值，不得用于产权交易、工商登记、融资

编制四原则

全面、客观、准确、概括；不得用模糊两可文字，未经查实事项如实披露

五大部分

①名称及文号 ②摘要 ③正文 ④附表 ⑤附件（《矿业权评估报告编制规范》）

摘要效力

与正文具有同等法律效力；由机构盖章、法定代表人签字、专业人员签章

统一编码

2017年起实施；未经编码的报告不在行业质量管理范围、协会不予认可；回执单列装封面/扉页

第一节 矿业权价值评估报告的概念与类型

1.1 基本概念

矿业权价值评估报告 = 矿业权价值评估专业人员按照国家有关法律、行政法规和矿业权评估准则，在履行了必要的评估程序后，对评估对象在评估基准日特定目的下的价值发表的、由其所在矿业权评估机构出具的书面专业意见。
  • 是矿业权价值评估项目的法定成果
  • 是矿业权价值评估项目最终的档案资料
  • 是矿业权评估机构及其矿业权价值评估专业人员的执业能力的体现

1.2 五种分类方式

划分标准类型要点
① 法律定位法定评估报告 / 非法定评估报告涉及国有资产或公共利益、法律法规规定需要的评估业务 → 法定
② 评估对象探矿权 / 采矿权 / 其他权益报告其他权益如矿业权出让收益评估报告
③ 评估业务类型出让 / 转让 / 企业国有资产交易 / 上市公司并购重组 / 法院涉执财产处置多用于统计、管理；需关注不同管理部门的具体要求
④ 评估基准日时点现时性 / 追溯性 / 预测性现时（基准日为现在）最常见，追溯次之，预测较少见

1.3 矿业权价值咨询评估报告与其他相关报告

（1）矿业权价值咨询评估报告

  • 适用情形：执行评估业务中部分评估程序受到限制，且限制对评估结论构成重大影响，委托人和相关当事人在报告出具前未能排除或未能完全排除限制的
  • 性质：限制使用性质，须披露使用限制条件及对评估结论可能造成的影响
  • 用途限制：仅供委托人和报告使用人了解矿业权价值，不能用于产权交易、工商登记、融资等
咨询评估报告也属于矿业权价值评估业务范畴，受《资产评估法》规范；《资产评估法》并未对其法律效力、执业责任另行规定 —— 因此教材强烈建议谨慎出具咨询评估报告。

（2）其他与矿业权价值评估业务相关的报告

指除矿业权价值评估业务外，围绕价值评估和咨询或为其提供基础/依据的业务，通常包括：

  • 矿产资源资产核算、矿产资源负债表编制
  • 矿业权出让收益市场基准价制定和（预）可行性研究报告
  • 矿床工业指标论证报告、生产能力论证报告
  • 综合开发利用方案、矿产资源开发利用方案等的编制业务

受托开展上述业务，应按相关规定、技术规范的要求出具报告。

①评估项目的法定成果 ②最终档案资料 ③评估机构及专业人员执业能力的体现

第二节 矿业权价值评估报告编制要求

矿业权评估机构、矿业权价值评估专业人员编制出具评估报告，应遵循《资产评估法》和矿业权价值评估准则的要求。

2.1 编制原则（四原则）

原则核心含义
全面完整反映评估中获取的有限事实和资料，以及根据这些事实和资料进行合理推断的过程和结论
客观对影响和决定评估价值的因素进行客观陈述、分析，评估结论应有充分依据
准确按准则术语和定义编制，用语准确，不得使用模糊两可或易生误解的文字；未经查实的事项如实披露，难以确定的事项客观说明事项本身及其对评估结论和使用的影响
概括用简洁文字概括必需内容，资料应在科学鉴别与分析基础上筛选，选有典型性、代表性、能反映事实本质特征的资料

2.2 编制基本要求（六项）

  1. 内容与附件资料齐全、配套、有效：按《资产评估法》和准则编制；报告须由评估机构盖章、法定代表人（执行合伙企业事务的合伙人）签字、承办专业人员签字盖章；法定评估业务报告的承办人员应为矿业权评估师；附件、附表、附图不但齐全，还应与报告配套、有效
  2. 清晰、准确陈述，不得有歧义和误导性表述：报告具有法律意义，除委托人、矿业权人、约定使用人和法律法规规定的使用人外，相关当事人及社会公众只能通过报告文字理解结论；用语不谨慎会引发误解、误导甚至误用
  3. 提供必要信息，使使用人能够全面理解和正确使用评估结论：明确报告使用者（一般为委托人＋法律法规规定的使用人，合同约定其他使用人也应明确）；呈现完整、可理解的评估结论——如基准日期后事项概率较大的要列举清楚，而非用“结论只针对基准日有效”的简单概括表述
  4. 根据项目复杂程度、委托人合理要求确定详略程度：⚠️ 矿业权价值评估报告不存在其他评估专业的简式评估报告，编制须遵循准则要求
  5. 使用语种与汇率符合要求：通常用中文撰写，同时出外文版本的以中文为准；结果一般以人民币为计量币种，用外币表示的应注明币种及与人民币在评估基准日的汇率
  6. 披露相关日期：评估基准日、评估结论使用有效期、评估报告日
签字盖章“三件套”：评估机构盖章 ＋ 法定代表人（执行合伙企业事务的合伙人）签字 ＋ 承办矿业权价值评估专业人员签字（签章）；法定评估业务的承办人员须为矿业权评估师。

📝 第二节 考点自测

Q1：编制原则有哪四个？哪个原则强调“不得使用模糊两可或易生误解的文字”？
全面、客观、准确、概括；“准确”原则
Q2：法定评估业务报告的承办人员有何特殊要求？
承办人员应为矿业权评估师
Q3：矿业权价值评估报告有没有“简式评估报告”？报告通常用什么语言？外币如何表示？
没有（不存在其他评估专业的简式评估报告）；通常用中文撰写，外文版本以中文为准；结果一般以人民币为计量币种，用外币须注明币种及与人民币在评估基准日的汇率

第三节 矿业权价值评估报告的基本内容

3.1 五大部分总览

根据《矿业权评估报告编制规范》，评估报告的基本内容包括五个部分：①评估报告名称及文号 ②摘要 ③正文 ④附表 ⑤附件

（一）名称及文号

  • 封面载明：评估报告名称及文号、评估机构全称、评估报告日
  • 文号格式：矿业权评估机构特征字 ＋ 专业种类特征字 ＋ 年份 ＋ 报告序号（简明、含机构特征字及年份序号）

3.2 摘要

（1）主要内容

摘要应提供（体现）报告的主要信息，方便使用人使用。通常包括：提示、评估对象、委托人、矿业权人、矿业权评估机构、评估目的、评估基准日、评估方法、评估主要参数、评估结果、特别事项说明等。

评估主要参数应随评估方法和模型确定：如采用折现现金流量法时，摘要应列示矿产资源储量类型和数量、可采储量、生产规模、评估计算的服务年限、产品方案、矿产品销售价格、固定资产投资、单位总成本费用、单位经营成本、折现率等 —— 且要与正文一致。

（2）签字和用印

由矿业权评估机构盖章、法定代表人（执行合伙企业事务的合伙人）签字和矿业权价值评估专业人员签章。

（3）效力

评估报告摘要具有与评估报告正文同等的法律效力。

3.3 正文十九项

#内容关键要求
一评估机构情况名称全称、地址、法定代表人、统一信用代码、探矿权采矿权评估资格证书及机构简介
二评估委托人与矿业权人情况委托人简要情况；矿业权人注册情况、企业类型、法定代表人、经营范围
三矿业权情况勘查/建设规划/生产经营基本情况；矿业权取得时间方式与有偿处置；交易情况与评估史
四评估目的说明对应的经济行为及满足使用者何种需要；评估目的唯一，表述明确清晰
五评估对象与范围按对象与范围要素组合详细描述，表述明确清晰，防止缺项
六评估价值的定义未在编制规范中明确要求，但有助于理解评估结论；定义=要素组合＋特定目的＋评估时点＋前提/假设条件（如服务年限30年）＋实际采用方法估算的价值数额；表述全面、明确、清晰
七评估基准日须与评估委托合同（业务约定书）约定的评估基准日一致
八评估依据法律行政法规、评估准则、经济行为依据、权属依据、取价依据及所引用专业报告等；披露准确、清晰
九矿产资源勘查和开发概况矿区位置交通/自然地理经济概况；地质工作概况与成果；地质概况（地层、构造、岩浆岩、围岩蚀变）；矿产资源概况（矿床特征、矿体特征、矿石质量、加工技术性能）；开采技术条件；勘查/开发利用现状
十评估程序履行情况完整、真实披露，包括评估程序的确定和履行
十一评估方法说明方法选择依据和理由并列示主要计算公式；具备条件且适合不同途径的应采用两种以上途径方法比较分析形成结论；无法采用两种以上的可用一种方法并披露理由
十二评估参数简述选取参数的依据/参考资料；列明各参数选取确定原则、依据、确定（计算）过程和结果（计算参数须列公式和结果）；引用专业报告须说明名称、形成时间、结论，调整须说明调整过程；利用专家协助须说明专家数量、专业资格、工作过程、结论及检查汇总分析过程
十三评估假设披露评估假设并说明其对评估结论的影响
十四评估结果以文字与数字形式表示，必要时完整说明评估价值定义与评估结果之间的关系
十五特别事项说明见下方要点框
十六评估基准日期后事项基准日至报告日期间发生、可能影响结论的事项（矿业权/矿产地重大变化如勘查阶段、重大自然灾害、国家政策变化、市场参数重大变化）
十七评估报告使用限制见下方要点框
十八签字和用印机构盖章、法定代表人签字、专业人员签章
十九评估报告日按准则规定载明
特别事项说明通常包括（11项）：①产权权属资料瑕疵 ②或有事项（未决事项、法律纠纷等）③引用专业报告/利用专家协助 ④不确定因素 ⑤委托人的特殊要求 ⑥受客观条件限制未履行必要评估程序的采取措施 ⑦提请使用者正确理解并合理使用报告（否则不承担相应法律责任）⑧尽职调查中未开展的、超出评估专业范畴的工作 ⑨委托人要求的、超出规范和专业范畴的工作 ⑩评估依据资料的真实性、完整性和合法性 ⑪其他需要说明的事项。
评估报告使用限制：报告所有权属于委托人。①使用有效期原则上自评估基准日起一年有效（委托人可根据管理需要确定）②只能由委托合同（业务约定书）中载明的使用人使用 ③只能服务于报告中载明的评估目的 ④除法律法规规定及当事方另有约定外，未征得评估机构同意，报告全部或部分内容不得被摘抄、引用或披露于公开媒体。

3.4 附表与附件

  • 附表：应在正文后附评估计算表
  • 附件：①评估对象所涉及的权属证明资料 ②委托人和相关当事人的承诺函 ③探矿权采矿权评估资格证书、承办专业人员执业登记证书（矿业权评估师还需附职业资格证书）④其他相关资料等

📝 第三节 考点自测

Q1：评估报告基本内容五大部分是什么？文号格式如何？
名称及文号、摘要、正文、附表、附件；文号＝评估机构特征字＋专业种类特征字＋年份＋报告序号
Q2：摘要的法律效力如何？采用折现现金流量法时摘要应列示哪些主要参数？
与正文同等法律效力；矿产资源储量类型和数量、可采储量、生产规模、服务年限、产品方案、矿产品销售价格、固定资产投资、单位总成本费用、单位经营成本、折现率等（须与正文一致）
Q3：正文共十九项，其中“评估方法”的选用原则是什么？
说明选择依据和理由并列示主要计算公式；具备评估资料条件且适合采用不同途径的应采用两种以上途径方法比较分析形成结论；因适用性、操作限制等无法采用的可用一种方法并披露理由
Q4：评估报告使用有效期原则上多长？报告所有权归谁？
原则上自评估基准日起一年有效（委托人可根据管理和工作需要确定）；所有权属于委托人

第四节 矿业权价值评估报告的管理

为加强对行业事中、事后监管，规范执业行为、提高报告质量、提升公信力、维护市场秩序，中国矿业权评估师协会自 2017 年起对矿业权价值评估报告实施统一编码管理。

4.1 统一编码范围

矿业权评估机构出具的各类矿业权价值评估报告（含矿业权价值评估准则中规定的矿业权价值咨询评估报告）全部纳入统一编码范围。

4.2 统一编码流程（六步）

评估机构指定专人负责，通过统一编码管理系统向中国矿业权评估师协会提出申请，系统自动配号并生成统一编码页面。

  1. 填报基础信息，确认并提出申请
  2. 上传报告：矿业权出让收益评估报告上传向自然资源行政主管部门提交前的公示稿，其他报告上传终稿
  3. 系统自动生成含编号、二维码、机构名称等信息的 A4 纸规格页面，名为《中国矿业权评估师评估报告统一编码回执单》
  4. 下载或打印回执单，出具正式报告时该回执单须列装在报告封面或扉页位置
  5. 存档：①出让收益评估报告经公示后无异议的，已上传公示稿视为公开稿并存档；有异议的须在报告公开后五个工作日内修改相关基本信息，将修改意见或说明及最终公开稿上传存档 ②其他报告统一编码完成后系统自动存档，确需修改的须将修改意见或说明及最终稿同时上传
  6. 评估机构须保证填写的基本信息、统一编码的最晚存档报告与最终提交给委托人的报告一致

4.3 使用、检查与管理

（1）使用

  • 应将《统一编码回执单》列装在报告封面或扉页位置
  • 未经统一编码的报告不在行业质量管理范围，中国矿业权评估师协会不予认可

（2）检查

  • 协会定期按比例抽取报告，按规定组织专家检查，结果反馈至相应评估机构
  • 协会不定期对系统中有修改意见或说明的报告抽查，重点审查修改部分或说明情况部分
  • 评估机构年检业绩以经过统一编码的评估报告为准

（3）管理（惩戒情形）

存在下列情形的，依据《中国矿业权评估师协会矿业权评估执业自律管理规定》等相关规定惩戒，记入诚信档案并向社会公开：

  1. 出具未经统一编码矿业权价值评估报告的
  2. 报告统一编码后未上传最终稿的
  3. 存在弄虚作假行为的
  4. 报告质量存在重大问题的
  5. 评估机构伪造编码出具报告的，从重惩戒
统一编码“一条红线”：未经统一编码的评估报告不在行业质量管理范围、协会不予认可；伪造编码出具报告从重惩戒并记入诚信档案向社会公开。

📝 第四节 考点自测

Q1：统一编码管理从哪一年开始？由哪个机构实施？
2017年起，由中国矿业权评估师协会实施
Q2：矿业权出让收益评估报告与其他报告在上传环节有何不同？
出让收益评估报告上传向自然资源行政主管部门提交前的公示稿；其他报告上传终稿
Q3：未经统一编码的报告有何后果？年检业绩以什么为准？
不在行业质量管理范围，协会不予认可；年检业绩以经过统一编码的评估报告为准
